# Nicolas Ferreira

Full Stack Developer based in Brazil. I build web and backend applications with .NET and modern JavaScript, and I am studying Analysis and Systems Development at IFSC. I currently work as a developer at Way2 Technology.

My main focus is Full Stack work with C# and ASP.NET Core on the backend and React with Next.js on the frontend. I also work with Java and Spring Boot, native Android in Kotlin, and I build computer vision projects in Python with PyTorch.

Backend: ASP.NET Core, Entity Framework Core, Spring Boot, REST APIs, JWT authentication

Mobile: Android, Kotlin
